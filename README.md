# SecondBrain

**A second brain your AI can use and you can inspect.**

Turn notes, decisions, and supported AI sessions into a searchable Markdown library. Keep the sources, build useful summaries, and carry context into the next conversation.

[Get started](BOOTSTRAP.md) · [Bring your existing notes](docs/MIGRATION.md) · [Technical guide](README.technical.md)

> “Where did we leave this project, and why did we choose that approach?”

SecondBrain gives you a path from that question to the relevant context and its original evidence.

## Why choose this over a traditional second brain?

A notes-first second brain helps you collect and organize information. This template adds an engine that helps your AI use it:

- **Less routine upkeep.** Capture supported agent sessions, generate summaries, and rebuild indexes with scripts.
- **Easier restarts.** Project pointers and retrieval tools help recover relevant notes and past decisions.
- **Answers you can check.** Follow summaries back to preserved sources and recorded checks.

**Capture → Summarize → Connect → Retrieve**

Your library stays in readable files you control. Use your preferred editor and adopt the automation that fits your routine.

Already use Obsidian or Notion? Start with a few notes using the [step-by-step migration guide](docs/MIGRATION.md).

## Start in three steps

1. Select **Use this template** to create your own private repository.
2. Follow the [setup guide](BOOTSTRAP.md) to connect your agent and model.
3. [Import a few notes](docs/MIGRATION.md), ask a real question, and check the answer against its sources.

The included integrations target Claude Code and Pi, with macOS-oriented scripts. Other environments need adaptation. Automatic project matching uses exact tags, and AI summaries need review.
